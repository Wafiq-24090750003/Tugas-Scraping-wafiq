# Scraping Kopi Kenangan

Project ini dibuat untuk tugas web scraping menggunakan Python.

## Tools
- Python
- Requests
- BeautifulSoup
- Pandas

## Proses
Script melakukan request ke website Kopi Kenangan, mengambil HTML, membaca judul website, kemudian menyimpan hasilnya ke CSV.

## Cara Menjalankan

```bash
pip install requests beautifulsoup4 pandas
python scraping.py
